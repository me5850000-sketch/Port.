Traker — فورم تسجيل الـ Tasks

الفورم اللي كل عامل بيسجّل بيه Task خلّصه لحظة بلحظة، مع validation صارم على كل حقل (الرقم القومي 14 رقم، شكل اللينك، طول الـ Task ID) عشان يمنع الغلط قبل ما يحصل. وفيه كشف فوري لو نفس الـ Task اتبعت قبل كده بدل ما يتكرر في الداتا — الجزء ده كان شغال على Supabase وتم نقله لسيستم مبني على Google Sheets عشان يبقى أسرع وأثبت.

How a Supabase-backed system like this actually runs

مفيش سيرفر لوحده في النص — الموقع الـ Static بيتكلم مباشرة مع Supabase عن طريق مفتاح anon key محمي بصلاحيات Row Level Security. اللي بيمشي الشغل هو ثلاث حاجات:

Auth

تسجيل الدخول وطلب الحساب بيتخزنوا في auth.users، والموافقة (Pending → Approved) بتتحكم فيها حالة في جدول profiles بيراجعها الأدمن.

→

Database

كل Task وLabeler وسجل حضور صف في جدول Postgres. فحص "الـ Task ده اتبعت قبل كده" هو استعلام بيدور على نفس الـ ID قبل ما يعمل insert جديد.

→

Realtime

مؤشر LIVE والـ Auto Reload بيبقوا subscription على تغييرات الجدول، أو polling كل فترة زمنية محددة (30s / 1m / 2m / 5m).

ملاحظة مهمة: من إعداد APPS_SCRIPT_URL الظاهر في Traker، ومن إنك نفسك نقلت فحص التكرار من Supabase لـ Google Sheets/GAS — يبقى النظام ده مش شغال بالكامل على Supabase دلوقتي، جزء منه (وممكن يكون أغلبه) بقى شغال على Apps Script. يعني اللي شفته Live أول ما فتحت اللينكات ممكن يبقى مزيج من الاتنين مش Supabase وحده.
